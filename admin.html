🔐 Secure Data Backup · Admin Only

Download an encrypted backup of Firestore Students, Teachers, Attendance, Applications, Salary and Salary Change History. This is an on-demand export; Google-managed automatic backups must be enabled separately.

🔑 Backup Encryption Password

Use a unique password of at least 14 characters. The backup is encrypted on your own device. Store this password in a password manager — a lost password cannot be recovered.

⚠ Automatic backup activation is not complete just because the workflow exists. A project owner must first approve billing and give the backup-schedule IAM permission, run the workflow once, then verify the first backup. Managed backups retain 28 days in the prepared setup, not forever.
